## Project Overview
This project implements a low-cost Internet of Things (IoT) system for remote residential door access control. The system utilizes a Raspberry Pi microcontroller connected to a webcam for capturing and analyzing images to detect visitor presence. Its primary aim is to improve residential security by providing authenticated, remote-controlled access to the main entrance.

## Repository Structure
Main Features:
- Remote access and control of door locking mechanism
- Real-time visitor monitoring with image capture
- Visitor presence detection using a webcam
- Integration of Raspberry Pi as the central controller
